# PROCESS 4.0 : AI Integration for Efficient and Reliable Production

End-of-studies project focused on developing an intelligent Industry 4.0 platform combining Business Intelligence and Artificial Intelligence for production monitoring and quality control.

## Overview

This project includes:

- 📊 Design of a complete decision-support system:
  - Data Warehouse architecture
  - ETL pipelines using SSIS
  - Data visualization and KPI monitoring with Tableau Desktop

- 🤖 Development of AI models for PCB defect inspection:
  - CNN model for defect classification
  - YOLOv5 model for defect detection and localization

- 🧠 Model training and optimization using:
  - Google Colab
  - Kaggle datasets

- 🌐 Development of a Flask web application:
  - Real-time image analysis
  - Defect prediction and annotation
